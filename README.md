# Mouse Trail

Windows 데스크톱 전체에서 마우스를 움직일 때 빛나는 꼬리가 따라오는 오버레이 앱.

- 화면 전체를 덮는 **클릭 관통 투명 오버레이** — 평소 작업 방해 없음
- **트레이 아이콘**에서 색·꼬리길이·자동실행 토글
- **다중 모니터** 지원
- **Windows 시작 시 자동 실행** 옵션

---

## 처음 한 번: 설치파일 만들기

빌드에 필요한 건 Node.js 하나뿐입니다.

### 1. Node.js 설치 (한 번만)
[nodejs.org/ko](https://nodejs.org/ko/) 에서 **LTS** 버전을 받아 설치하세요.

### 2. 빌드 실행
이 폴더 안에 있는 **`build.bat` 파일을 더블클릭** 하세요.
- 의존성을 다운로드하고 (~150MB)
- `dist/` 폴더에 `MouseTrail-Setup-1.0.0.exe` 가 생성됩니다 (몇 분 소요).

### 3. 설치
생성된 `MouseTrail-Setup-1.0.0.exe` 를 실행하면 일반 Windows 프로그램처럼 설치됩니다.
- 시작 메뉴 / 바탕화면 바로가기 자동 생성
- 제거는 [설정 > 앱]에서 일반 프로그램과 동일하게.

---

## 사용법

설치 후 **Mouse Trail** 을 실행하면 트레이(작업 표시줄 우측 시계 옆)에 보라색 점 아이콘이 나타납니다.

아이콘을 **클릭**하면 메뉴:

| 메뉴 | 설명 |
|-----|------|
| 활성화 | 효과 켜기/끄기 (체크박스) |
| 색상 | 보라 / 시안 / 주황 / 그린 / 핑크 / 화이트 |
| 꼬리 길이 | 짧게 / 보통 / 길게 |
| Windows 시작 시 자동 실행 | 부팅하면 자동으로 켜짐 |
| 종료 | 프로그램 완전 종료 |

## 개발자용

```bash
npm install
npm start          # 개발 모드로 실행
npm run dist       # 설치파일 빌드
```

### 파일 구조
- `main.js` — Electron 메인 프로세스. 투명 오버레이 창 생성, 커서 위치 폴링(~120Hz), 트레이 메뉴
- `preload.js` — IPC 브릿지
- `index.html` / `renderer.js` — 캔버스에 3겹 글로우 곡선 렌더링
- `package.json` — `build` 섹션에 electron-builder 설정 (NSIS 인스톨러)

### 색을 추가하고 싶다면
`main.js` 의 `colors` 배열에 `{ name: '이름', val: 'R,G,B' }` 형태로 항목 추가.
